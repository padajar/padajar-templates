``padajar-templates`` is a set of templates created by Phi Adajar (phiadajar@mit.edu) in Spring 2025, with clean templates for memos, papers, psets, and slides, built on their earlier format (since deprecated). Current version: v1.5.0 (2026-10-04).

Files: ``padajar-defaults.sty`` (shared package), ``padajar-memo.cls``, ``padajar-paper.cls``, ``padajar-pset.cls``, ``padajar-slides.cls``, and ``aea.bst`` (AER bibliography style). Compile with XeLaTeX or LuaLaTeX. Examples of each class are in ``memo/``, ``paper/``, ``pset/``, and ``slides/``.

For usage, the changelog, and installation, view ``padajar-templates.pdf``.
