``padajar-templates`` is a set of templates created by Phi Adajar (phiadajar@mit.edu) in Spring 2025, with clean templates for memos, papers, psets, and slides. They created these templates in 2025, based upon their earlier format which has since been deprecated.

For more information on usage, view ``padajar-templates.pdf``.
